# مساعد حساسية فري فاير — مشروع Android بشات وصوت

## المميزات
- واجهة عربية للمحادثة.
- إدخال صوتي بالعربية عبر خدمة التعرف على الكلام المتاحة على الجهاز (قد تستخدم الإنترنت حسب خدمة Android).
- قراءة رد المساعد بصوت عربي عبر TextToSpeech إذا كانت لغة العربية مثبتة في محرك الصوت.
- نصائح محلية مبدئية للحساسية والتقطيع.
- زر نسخ إعدادات الحساسية.
- نقطة ربط اختيارية لخادم ذكاء اصطناعي عبر HTTPS.

## حدود النسخة الحالية
- هذا مشروع Android وليس APK جاهزًا.
- الردود الحالية محلية وليست نموذج ذكاء اصطناعي حقيقيًا حتى يتم إعداد خادم.
- لا يراقب التطبيق اللعب أو الشاشة تلقائيًا؛ يحلل النص الذي تكتبه أو تمليه.
- لا يغيّر إعدادات Free Fire تلقائيًا ولا يضمن الهيدشوت.

## تفعيل الذكاء الاصطناعي أونلاين
1. جهّز خادم HTTPS خاصًا بك مع مسار POST اسمه `/chat`.
2. يرسل التطبيق JSON بالشكل:
   `{"message":"السحب بيطلع فوق الرأس","device":"Samsung Galaxy Tab A7","game":"Free Fire"}`
3. يجب أن يرجع الخادم JSON بالشكل:
   `{"reply":"جرّب تقليل الحساسية العامة بمقدار 5 درجات..."}`
4. غيّر قيمة `AI_ENDPOINT` في `MainActivity.java` إلى رابط الخادم الفعلي.
5. ضع مفتاح مزود الذكاء الاصطناعي على الخادم فقط، لا تضعه داخل APK.
6. أضف إلى الخادم حدود استخدام وحماية مناسبة، ولا تسجل محادثات المستخدم إلا بموافقته.

## بناء APK
افتح المجلد في Android Studio، انتظر Gradle Sync، ثم اختر Build > Build APK(s).

## طريقة استخراج APK بدون تثبيت Android Studio على التابلت
أضف هذا المشروع إلى مستودع GitHub خاص أو عام من جهاز كمبيوتر، ثم افتح تبويب **Actions** وشغّل **Build Android APK** عبر **Run workflow**. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل الملف من **Artifacts** باسم `FreeFireAI-debug-APK`، ثم انقله إلى التابلت وثبّته. قد يطلب Android السماح بالتثبيت من مصدر الملف الذي استخدمته.

**ملاحظة:** هذا المسار يبني APK تجريبيًا من المشروع. لا يزال الاتصال بخادم ذكاء اصطناعي حقيقي غير مفعّل؛ النسخة الحالية تقدم نصائح محلية وتستخدم خدمات الصوت المتاحة على الجهاز.
